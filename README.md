# Aplicație pentru Preluarea și Prelucrarea Comenzilor
**Proiect Baze de Date**

## Scop
Proiectarea unei baze de date pentru gestionarea eficientă a clienților, produselor, comenzilor și a fluxului de livrare pentru un magazin/furnizor.

## Obiective
Sistemul permite operații CRUD pentru preluarea comenzilor, actualizarea stocurilor și urmărirea livrărilor.

## Structura Proiectului
- `docs/`: Documentația proiectului
- `db/`: Scripturi SQL și diagrame
- `app/`: Aplicația practică conectată la BD
- `teste/`: Scripturi pentru testarea constrângerilor
